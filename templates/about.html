Dataset Specification: UCI Cleveland Heart Disease

The gold-standard cardiology benchmark collected from the Cleveland Clinic Foundation by Robert Detrano, M.D., Ph.D.

The Cleveland database contains 303 patient records across 14 measured attributes. The original clinical target measures angiographic coronary artery disease narrowing: 0 represents < 50% diameter narrowing (absence of significant disease), while values 1, 2, 3, 4 represent > 50% diameter narrowing (presence of significant disease). In accordance with modern cardiology ML research, the target is binarized into:

y = 1 if target > 0 else 0 (Positive: 139 patients, Negative: 164 patients)
Feature Name Clinical Significance Data Type / Physiological Bounds
age Patient age in years Continuous (18 – 120 years)
sex Biological sex Binary (1 = Male, 0 = Female)
cp Chest pain classification Categorical (1 = Typical angina, 2 = Atypical angina, 3 = Non-anginal, 4 = Asymptomatic)
trestbps Resting blood pressure on hospital admission Continuous (80 – 240 mm Hg)
chol Serum cholesterol Continuous (100 – 600 mg/dl)
fbs Fasting blood sugar > 120 mg/dl Binary (1 = Diabetic threshold, 0 = Normal)
restecg Resting electrocardiographic results Categorical (0 = Normal, 1 = ST-T abnormality, 2 = LV hypertrophy)
thalach Maximum exercise heart rate achieved Continuous (60 – 220 bpm)
exang Exercise-induced angina Binary (1 = Yes, 0 = No)
oldpeak ST depression induced by exercise vs rest Continuous (0.0 – 10.0 mm)
slope Slope of the peak exercise ST segment Categorical (1 = Upsloping, 2 = Flat, 3 = Downsloping)
ca Number of major vessels (0-3) colored by fluoroscopy Discrete (0, 1, 2, 3 vessels)
thal Thallium scintigraphy perfusion defect Categorical (3 = Normal, 6 = Fixed defect, 7 = Reversible defect)

REST API Reference: /api/predict

Programmatic risk prediction endpoint accepting JSON payloads for integration into EHR systems and clinical workflows.

Endpoint: POST /api/predict

Content-Type: application/json
